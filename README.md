# post-request-recommendations-prototype
M2 UX prototype: post-request recommendations (school project, fictional data)

1. Telecharger et dezipper le dossier.
2. Double-cliquer sur "index.html" (Chrome, Safari ou Edge). Aucune installation, aucune connexion internet requise.
3. Conseil : ouvrir en plein ecran sur ordinateur. Touche D : barre de demo (version V1/V2, vitesse de l'animation).
4. Pour recommencer le parcours : ajouter ?reset a la fin de l'adresse.

"Demo-video.mov" : video de demonstration (43 s).

Projet pedagogique (M2 UX). Donnees, photos et profils fictifs. Usage strictement evaluatif.
